📋 YÊU CẦU HỆ THỐNG
--------------------
- Windows 10/11
- Python 3.9 trở lên (tự động kiểm tra khi cài)
- Kết nối Internet (để tải thư viện lần đầu)
- Raspberry Pi đang chạy với MQTT broker


🚀 HƯỚNG DẪN CÀI ĐẶT (CHỈ LÀM 1 LẦN)
======================================

BƯỚC 1: Cài Đặt Thư Viện
-------------------------
1. Double-click file: install.bat
2. Chờ cài đặt (1-2 phút)
3. Khi hỏi API Key:
   - Truy cập: https://aistudio.google.com/app/apikey
   - Tạo API key mới (MIỄN PHÍ)
   - Copy và paste vào
4. Đợi thông báo "Cài đặt hoàn tất!"

BƯỚC 2: Test API Key
---------------------
1. Double-click file: test_api.bat
2. Xem kết quả:
   - [OK] API KEY HOẠT ĐỘNG TỐT! → Tiếp tục bước 3
   - [X] API KEY LỖI! → Kiểm tra lại API key

BƯỚC 3: Kiểm Tra Kết Nối
-------------------------
1. BẬT Raspberry Pi (chờ 2 phút khởi động)
2. Kết nối WiFi:
   - SSID: CLASS-BOX
   - Pass: 12345678
3. Double-click file: check_status.bat
4. Xem kết quả:
   - [✓] Raspberry Pi: ONLINE → OK!
   - [✗] Raspberry Pi: OFFLINE → Kiểm tra lại


🎯 CHẠY AI SERVICE (MỖI KHI SỬ DỤNG)
=====================================

1. Double-click file: start.bat
2. Cửa sổ đen hiện ra với:
   ✓ AI Teaching Assistant initialized with RAG + Caching
   ✓ Vector DB initialized
   ✓ Connected to MQTT Broker
   ✓ AI service started. Waiting for requests...
3. XONG! Giữ nguyên cửa sổ, ĐỪNG TẮT!


🌐 SỬ DỤNG WEB DASHBOARD
=========================

1. Mở trình duyệt
2. Vào: http://192.168.4.1:8000
3. Tính năng:
   - Teacher Chat: Hỏi AI trực tiếp
   - Documents: Upload tài liệu bài giảng (PDF/DOCX/TXT)
   - Monitor: Xem học sinh đang hỏi gì


🧪 KIỂM TRA HOẠT ĐỘNG
======================

Test 1: Qua Dashboard
---------------------
1. Vào http://192.168.4.1:8000
2. Tab "Teacher Chat"
3. Gõ: "Giải phương trình 2x + 4 = 0"
4. Nếu AI trả lời → THÀNH CÔNG!

Test 2: Upload Document
-----------------------
1. Tab "Documents"
2. Upload file bài giảng (PDF/DOCX/TXT)
3. Xem log AI Service:
   "Indexed X chunks into vector DB" → OK!

Test 3: ESP32 Glasses
---------------------
1. Nhấn nút AI mode trên kính
2. Nói câu hỏi
3. Xem response trên màn hình OLED


🛠️ TROUBLESHOOTING
==================

Vấn Đề 1: Web "chờ mãi" không kết nối AI
----------------------------------------
→ Chạy check_status.bat
→ Xem phần nào [✗] và làm theo hướng dẫn

Vấn Đề 2: API Key lỗi
---------------------
→ Mở file config.env bằng Notepad
→ Thay API key mới
→ Chạy lại test_api.bat

Vấn Đề 3: Không kết nối Raspberry Pi
------------------------------------
→ Kiểm tra Pi đã bật chưa
→ Kiểm tra WiFi đã nối CLASS-BOX chưa
→ Thử ping: ping 192.168.4.1

Vấn Đề 4: Python lỗi
--------------------
→ Cài Python từ: https://www.python.org/downloads/
→ Tick "Add Python to PATH" khi cài
→ Chạy lại install.bat
